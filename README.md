    API Links Plugin
</h1>

Provides quick-access links to API endpoints for tracks, artists and albums using an External URL Source.

## Installation

Clone the repo into your [Pipe Bomb server's](https://github.com/pipe-bomb/server) `plugins` directory. Then inside, run:

```bash
npm ci
npm run build
```
